# InsigniaDeCategoria

La categoría de dato personal según la **Ley 1581 de 2012** (Colombia). **Color y texto, siempre los
dos**: el color solo no es información accesible.

| Prop        | Tipo               |
| ----------- | ------------------ |
| `categoria` | `CategoriaLey1581` |

Los valores y sus etiquetas viven en `ETIQUETAS_DE_CATEGORIA`, exportado del mismo módulo — léelo
antes de inventar una categoría.

```jsx
<InsigniaDeCategoria categoria="sensible" />
```
