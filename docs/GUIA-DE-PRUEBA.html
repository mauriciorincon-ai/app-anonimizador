Guía de prueba

Todas las pruebas vigentes de Velo. Este es el primer sprint, así que todas son nuevas; a partir del siguiente convivirán con las heredadas (regresión) y verás su origen en cada línea. Las casillas se guardan solas en este navegador.

Gate mínimo ⭐: 8 pruebas · ~18 min. Es lo único que ninguna automatización puede verificar: juicio humano sobre el diseño y el lenguaje, y las dos comprobaciones que solo valen si las haces tú con tus propias herramientas (la huella SHA-256 y el reporte abierto sin internet). Todo lo demás lo respalda la CI —260 pruebas unitarias, 39 e2e, axe en dos temas, presupuestos de rendimiento— y se corre en pases completos.

URL de prueba

https://app-anonimizador-git-sprint-001-el-diagnostico-mauricio-rincon.vercel.app

Dirección estable de la rama: no cambia aunque se suban correcciones. Si pide login de Vercel: Settings → Deployment Protection → Vercel Authentication → Disabled.

Cada bloque abre con "Empieza en:" — la ruta exacta (sobre esta URL) donde arranca su primera prueba. Navega ahí antes de empezar el bloque.

Kit de prueba — ni un dato real, nunca. Todos los archivos de prueba se generan con el generador sintético del repo (docs/kit-de-prueba/generador.mjs). Con la misma semilla producen el mismo archivo, byte por byte. Genera los tres que usa esta guía antes de empezar:

node docs/kit-de-prueba/generador.mjs --filas 3000   --seed 42 --perfil clinico        --salida tmp/clinico-3000.csv
node docs/kit-de-prueba/generador.mjs --filas 1200   --seed 7  --perfil sin-personales --salida tmp/limpio.csv
node docs/kit-de-prueba/generador.mjs --filas 1000   --seed 42 --perfil clinico --formato xlsx --salida tmp/clinico.xlsx
node docs/kit-de-prueba/generador.mjs --filas 500000 --seed 42 --perfil clinico        --salida tmp/clinico-500k.csv

El último pesa unos 130 MB y tarda un par de segundos. Nunca uses un archivo real de una persona para probar: este repo es público y el kit existe justo para eso.

G

Excel

Empieza en: / · ~2 min · la otra vía de lectura, con su tope declarado.

Kit de prueba: tmp/clinico.xlsx — mismo generador, --formato xlsx.

Diferido: probar a mano un Excel de más de 150 MB no es razonable (generarlo tarda y ocupa). El rechazo por tamaño está cubierto por pruebas automáticas: un e2e fabrica un archivo de 160 MB en el navegador y comprueba que Velo lo rechaza sin abrirlo y guía a CSV.
